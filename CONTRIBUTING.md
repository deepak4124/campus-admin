# Contributing

## Branching and PRs
- Follow .github/branching-conventions.md.
- Use the PR template in .github/pull_request_template.md.
- All changes go through PR review.

## Code standards
- Use professional language and no emojis in code, comments, and docs.
- Follow SOLID principles and prefer modular, class based design where appropriate.
- Keep functions small, focused, and testable.

## Commit messages
- Use short, imperative messages.
- Example: "add admissions form scaffold".

## Development setup
- Backend: pip install -r backend/requirements.txt
- Frontend: npm install --prefix frontend
